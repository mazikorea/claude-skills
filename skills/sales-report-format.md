# 매출 리포트 서식 스킬

## 0. 적용 범위와 정본
- **MAZI/COSSET 정기 DAILY·WEEKLY**의 렌더·발행 정본은 Buddy(Hermes)의 `sales-report-format` 스킬(claude-import/productivity, 2026-09-08 확정 골든 이미지 양식)이다. 정기 리포트를 이 문서의 텍스트 구조나 임의 축약본으로 대체하지 않는다. 지표 정의가 이 문서와 다르면 Buddy 정본을 따른다.
- 이 문서는 비정기 분석, 임시 요약, 엑셀 리포트, GAS 리포트 코드 작성에 적용한다.
- 세일즈 한정 데이터 분석(채널별 매출·소진율·베스트셀러·재고)은 `mazikorea-sales-md` 위임 대상이다.

## 1. 보고 순서
1. 결론: 매출/목표/전일 또는 전주 대비 핵심 변화.
2. 원인: 채널, 상품, 행사, 재고, 할인 영향.
3. 리스크: 재고 부족, 할인 미적용, 정산/주문 누락.
4. 다음 액션: 담당자와 기한.

## 2. 정기 보고 원천 (2026-11-02)
- MAZI/COSSET 정기 보고는 적재 완료 기록과 대상 날짜를 확인한 뒤 세일즈 대시보드 집계를 기존 골든 양식에 표시한다. 적재 단계에서 끝낸 전체 원장 대조·매핑·재무 검증을 보고 단계에서 반복하지 않는다.
- 순매출·수량·목표·비용·비교값은 대시보드 정의와 단위를 유지한다. 집계가 있는 숫자를 별도 원장 증빙 부족으로 보류하지 않는다. 실제 없는 지표만 사유와 함께 N/A로 둔다.
- 원천 오류 조사는 적재 담당 경로로 분리하고, 확정 연결·수동 정정·품번 계절 우선 규칙은 다음 적재에도 유지한다.
- 기존 승인·발신자·일간/주간 채널·중복 방지·게시 재조회는 Buddy 정본대로 유지한다.

## 3. 공통 표기 규칙
- **표 중심**. 금액·수량·퍼센트는 우측 정렬, 텍스트는 좌측.
- **기준일**을 반드시 표시한다. 원천 Sheet/DB의 기준일이 다르면 합산하지 말고 WARN으로 분리한다.
- **A/R**: Achievement Rate (목표 대비 달성률). 항상 "A/R XX.X%" 형태로 표기.
- **전일비/전주비**: ▲(증가)/▼(감소) + 퍼센트.
- **숫자**: 천 단위 콤마 필수, 원 단위 표기. 비중은 소수점 1자리. % 지표의 변화는 %p, 금액·수량의 변화는 %.
- **추정치**는 신뢰도와 한계를 표시한다.
- **이모지 최소화**: 섹션 구분은 [ ] 대괄호로.
- **요약 3줄**: 바쁜 경영자가 이것만 보고 판단할 수 있는 내용만. "신규 판매 상품" 같은 저가치 정보 제외. 핵심은 매출 달성률, 가장 큰 채널 변동, 이익률 변화.

## 4. 텍스트 요약 구조 (비정기·임시 요약용)

정기 DAILY·WEEKLY에는 쓰지 않는다. 임시 분석을 Slack·대화에 텍스트로 공유할 때의 기본 순서.

```
[브랜드명] | YYYY-MM-DD (요일) [일일/주간] 요약

[ 요약 ]
• 순매출 X원  A/R XX.X%, 전일비(전주비) ±X.X%
• 채널 중 가장 큰 변동: [채널명] 전일비 ▲/▼XX%
• 공헌이익률 XX.X% (전일비 ±X.X%p)

[ 매출 실적 ]
순매출     X,XXX,XXX원      A/R XX.X%
목표       X,XXX,XXX원
판매수량   XX개             객단가 XXX,XXX원
공헌이익   X,XXX,XXX원      이익률 XX.X%

[ 할인 현황 ]
전체  XX.X%  (자사 X.X% / 유통 X.X%)

[ 채널별 실적 ]
채널       매출          비중      A/R      전일비
------------------------------------------------

...

[ 브랜드별 ]  ← MAZI / COSSET 구분

--------------------------------------
...

[ 에이징별 ]

--------------------------------------
```

## 5. 엑셀/스프레드시트 리포트

⚠️ 컬러, 폰트, 테두리 등 공통 서식은 **document-formatting 스킬**을 따른다.

### 시트 구성 원칙 (매출 리포트 전용)
- 좌측 식별 열: 시트명 | 구분 | 채널
- 데이터 영역 순서: YTD → MTD → DAY → Year → Month → Week
- 섹션 순서: 매출액(원) → 매출비중(%) → 부담 매출액 → 부담 매출비중(%)
- Online/Offline 소계 후 채널별 상세 행 배치

### 채널 목록
세일즈 대시보드의 상위분류·하위 채널을 그대로 쓴다. 대시보드에 없는 분류를 추정해 만들지 않는다. 브랜드별 입점 채널이 다르므로(예: COSSET은 일부 위탁몰 미입점) 빈 채널을 0으로 채우기 전에 입점 여부를 확인한다.

## 6. GAS 슬랙 리포트 코드 작성 시 (리포트 전용 규칙)
- 숫자 포맷 함수 반드시 분리: `formatNumber(num)`, `formatPercent(num)`
- 슬랙 메시지는 코드블록(```)으로 표 구현 → 고정폭 정렬
- Goal 데이터와 실적 데이터의 날짜 매칭 로직을 반드시 검증
- 에러 발생 시 슬랙으로 에러 메시지 전송 (빈 메시지 방지)
- 데이터 미입력 시 1시간 간격 재시도 로직 포함
- 구현 상세(CONFIG·트리거·재시도·배포)는 gas-automation 스킬을 따른다.

## 7. 주간 리포트 추가 항목
- 요일별 매출 추이 (패턴 파악용)
- 주간 할인율 추이
- 채널별 객단가
- 전주 대비 증감률
