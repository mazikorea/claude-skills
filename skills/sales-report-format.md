# Sales Report Format

## Trigger
매출리포트, 실적보고서, 데일리, 위클리, 누적실적, 채널별 매출, 소진율.

## Report Order
1. 결론: 매출/목표/전일 또는 전주 대비 핵심 변화.
2. 원인: 채널, 상품, 행사, 재고, 할인 영향.
3. 리스크: 재고 부족, 할인 미적용, 정산/주문 누락.
4. 다음 액션: 담당자와 기한.

## Format
- 표 중심.
- 금액/수량/퍼센트는 우측 정렬.
- 날짜 기준일을 반드시 표시.
- 추정치는 신뢰도와 한계를 표시한다.

## Guardrails
- 세일즈 한정 데이터 분석은 `mazikorea-sales-md` 위임 대상이다.
- 원천 Sheet/DB 기준일이 다르면 합산하지 말고 WARN으로 분리한다.

## 정기 보고 원천 (2026-11-02)
- MAZI/COSSET 정기 보고는 적재 완료 기록과 대상 날짜를 확인한 뒤 세일즈 대시보드 집계를 기존 골든 양식에 표시한다. 적재 단계에서 끝낸 전체 원장 대조·매핑·재무 검증을 보고 단계에서 반복하지 않는다.
- 순매출·수량·목표·비용·비교값은 대시보드 정의와 단위를 유지한다. 집계가 있는 숫자를 별도 원장 증빙 부족으로 보류하지 않는다. 실제 없는 지표만 사유와 함께 N/A로 둔다.
- 원천 오류 조사는 적재 담당 경로로 분리하고, 확정 연결·수동 정정·품번 계절 우선 규칙은 다음 적재에도 유지한다.
- 발행 운영의 상세 정본은 맥미니 `~/.hermes/skills/claude-import/productivity/sales-report-format/SKILL.md`다. 기존 승인·발신자·일간/주간 채널·중복 방지·게시 재조회는 유지한다.
