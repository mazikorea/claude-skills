# AI 티 검수

화면이 "AI가 기본값으로 뽑은 것"처럼 보이는 이유를 측정 가능한 항목으로 바꿔 판정한다. 한 항목만으로는 증거가 아니고, **기본값이 여러 개 겹칠 때** AI 티로 본다. 수정 전 반드시 실제 화면(headless 캡처)과 DOM 측정을 직접 본다. 추정으로 판정하지 않는다.

## 사용 절차
1. 대상 화면을 1440·390 폭으로 캡처하고 CSS 계산값을 측정한다(아래 측정 스니펫).
2. 독립 판정자(Opus xhigh 등 별도 에이전트, 읽기 전용)에게 이 체크리스트와 캡처 경로를 주고 항목별 PASS/WARN/FAIL을 받는다. 수정한 본인은 판정하지 않는다.
3. 상·중 항목만 고치고 같은 방식으로 재캡처·재측정한다. 같은 항목이 2회 연속 FAIL이면 원인(토큰·공용 CSS)부터 다시 본다.
4. 보고는 `검토 모델`, 항목별 판정, 직접 본 근거(좌표·값), 수정 전후 캡처 순서로 한다.

## 체크리스트 (ID는 보고에 그대로 쓴다)

### A. 테두리·윤곽 (가장 흔한 티)
- A1 검정(또는 #1B1B1B 계열) 1.5~2px 실선 테두리 버튼·칩·입력창. 실제 에디토리얼 몰은 1px 연회색(#DDD~#E5E5E5) 헤어라인이거나 면(배경색) 또는 밑줄로 처리한다.
- A2 모든 요소에 같은 테두리·같은 모서리를 일괄 적용(카드·버튼·입력·칩이 한 틀).
- A3 선택 상태를 두꺼운 검정 박스 + 안쪽 인셋 그림자로 표시(사이즈·색상 선택기).
- A4 카드 왼쪽 굵은 색 줄(left-border accent), 그라디언트·글로우 테두리, 회전 테두리.
- A5 박스로 감싼 정보 블록(테두리 + 배경 + 패딩)이 3개 이상 나란히 반복.

### B. 색·장식
- B1 브랜드색이 내비·버튼·링크·테두리·뱃지·포커스링에 동시에 퍼짐. 포인트색은 한두 곳에만.
- B2 순수 검정(#000)·검정에 가까운 큰 면(푸터·바) — 레퍼런스가 흰/연회색이면 불일치.
- B3 그라디언트·글래스모피즘·글로우·부드러운 회색 그림자로 떠 있는 카드.
- B4 이모지·아이콘 장식, 의미 없는 구분선·점선.
- B5 보라-파랑 계열 그라디언트, 입체 버튼.

### C. 타이포
- C1 기본 스케일(12/14/16/18/24/30/36/48) 그대로 + 굵기 600·700 남발.
- C2 한글에 영문용 자간(letter-spacing .08em 이상)·전체 대문자 라벨(NEW, SHOP, VIEW MORE).
- C3 제목이 본문·상품명보다 과하게 크거나 모든 제목이 같은 크기.
- C4 위계가 없음(모든 글자 14~16px, 같은 굵기).

### D. 카피
- D1 일반적·무난한 문장("편안하고 안심되는", "당신의 일상을 더 특별하게"). 구체 사실(소재·치수·공정) 없음.
- D2 3박자 나열, 슬로건형 부제, 가운뎃점 제목.
- D3 모든 CTA가 "○○ 보기/더보기/자세히".
- D4 설명조·안내조 문장이 화면 곳곳에 반복(툴팁·도움말형 문장).

### E. 구성·리듬
- E1 같은 모양(50:50 2분할, 같은 카드 격자)이 반복. 구간 간격이 모두 같음.
- E2 중앙 정렬 히어로 + 버튼 2개 + 카드 3~4열이라는 기본 틀.
- E3 정보를 균질한 박스 그리드로 나열(서비스 4칸, 신뢰 배지 줄).
- E4 큰 빈 공간이 의도 없이 남음(정렬 기준 없이 가운데 배치).

### F. 이미지·데이터
- F1 상품 썸네일을 크게 늘려 히어로로 재사용(같은 사진 중복).
- F2 가짜 후기·별점·영상·숫자(임의 평점, 역산한 정가).
- F3 화면에 개발 메모·시연용 안내가 남음.
- F4 모든 컷이 같은 구도·배경(카탈로그 느낌만 있고 장면 사진 없음).

### G. 상호작용
- G1 호버 확대·떠오름·그림자 전환이 전 요소에 동일.
- G2 모든 버튼이 같은 중요도(주 버튼·보조 버튼 구분 없음).
- G3 토스트·모달·칩이 화면 위를 떠다니며 본문을 가림.

## 측정 스니펫 (playwright, headless)
- 테두리: 모든 `button,a,input,select,label,[class*=chip],[class*=btn]`의 `border-top-width/color/style`을 모아 `border:1.5px+검정` 개수를 센다.
- 색: `getComputedStyle`로 `background-color`가 #000~#222인 큰 요소(면적 비율)와 포인트색이 쓰인 속성 종류 수.
- 글자: 한글 텍스트 노드의 `letter-spacing`>0.05em 개수, `font-weight`≥600 개수, 영문 전체 대문자 라벨 개수.
- 반복: 같은 레이아웃 클래스가 한 화면에서 몇 번 쓰였는지.

## 판정
- FAIL: A·B 항목 중 화면에서 보이는 게 3개 이상이거나, 화면 결함(겹침·잘림) 1개 이상.
- WARN: 위 기준 미만이지만 C~G에서 2개 이상.
- PASS: 이외. 실제 기기·Safari 미확인은 UNVERIFIED로 별도 표기.
