# 단계 1: 가설 시험 (미확인 항목, 추측 금지)

아래는 공개 근거를 못 찾은 항목이다. **복제 스킨에서 실측**하기 전에는 구현 가정으로 쓰지 않는다. 복제 스킨 접근에 사람 로그인이 필요할 수 있으며, 이 스킬은 로그인을 시도하지 않는다. 결과가 확정되면 이 파일의 '결과' 열을 채워 점차 축소한다.

| # | 가설 시험 | 확인 방법 | 결과 |
|---|---|---|---|
| H1 | 복제 스킨을 대표 디자인 전환 없이 외부 URL로 미리보는 방법 | 관리자 미리보기 기능·URL 파라미터 여부 확인(사람) | 미확인 |
| H2 | 상품 상세 에디터가 `<video>`·`<script>`·`<iframe>` 및 `autoplay/muted/playsinline` 속성을 저장 시 보존하는가 | 복제 스킨 상세에 시험 마크업 저장 후 렌더 HTML 대조 | 미확인 |
| H3 | 외부 mp4·GLB·USDZ 로드와 Content-Type, 영상 용량 상한 | 외부 호스팅 파일 로드 + 응답 헤더 확인. 카페24 업로더 직접 업로드는 mp4 등 제한(공식) | 미확인 |
| H4 | 스킨의 CSP·외부 CDN 스크립트 허용 범위 | 시험 스크립트 삽입 후 `render_check.mjs`의 `csp-refused` 확인 | 미확인 |
| H5 | jQuery 중복 로드·GSAP 등 라이브러리 충돌 | `render_check.mjs`의 `jquery-duplicate`, 콘솔 오류 확인 | 미확인 |
| H6 | 목록 모듈에서 품절·옵션·사이즈 변수 사용 가능 범위 | 공식 문서 못 찾음. 시험 마크업으로 렌더 확인 | 미확인 |
| H7 | 호버 이미지 교체(`{$image_medium}`·`{$image_small}`)가 `product_listnormal`에서 동작하는가 | 시험 마크업 + hover 에뮬 | 미확인 |
| H8 | 앱스토어 앱(영상·리뷰·사이즈·선물) 설치 시 스킨에 주입되는 코드와 해지 시 잔재 | 복제 스킨에 설치 후 스킨 diff(`static_diff.mjs`) | 미확인 |
| H9 | 우리 스킨이 스마트디자인Easy인지 일반 스마트디자인인지(상속 기능 차이) | 관리자 확인(사람) | 미확인 |
