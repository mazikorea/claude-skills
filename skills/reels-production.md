# Reels Production

## Trigger
릴스 만들어, 릴스 제작, 숏폼, 후킹 문구, 콘티.

## Workflow
1. 상품/목표고객/목적을 정한다.
2. 3초 후킹, 장면 순서, 자막, CTA를 분리한다.
3. 실물 왜곡이 큰 AI 이미지는 최종컷보다 콘티/시안에 사용한다.
4. 광고용이면 A/B 테스트할 훅을 여러 개 만든다.
