# CRM Strategy

## Trigger
CRM, 세그먼트, 쿠폰, 리텐션, 재구매, 고객군, 휴면고객.

## Workflow
1. 고객 세그먼트를 MECE로 나눈다.
2. 각 세그먼트별 목표 행동을 정한다.
3. 쿠폰/메시지/타이밍/채널을 분리한다.
4. 실험군/대조군 또는 전후 비교 기준을 둔다.

## Guardrails
- 할인 남발은 브랜드 가치와 마진을 훼손할 수 있으므로 목적 없는 쿠폰 제안 금지.
- 개인정보/수신동의/외부 발송은 승인 경계로 둔다.
