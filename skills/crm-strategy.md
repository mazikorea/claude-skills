# CRM 전략 스킬

## 적용 대상
MAZI UNTITLED, COSSET COSSET 자사몰(Cafe24) 기준. 위탁몰(무신사, 29CM 등)은 CRM 직접 제어 불가하므로 자사몰 중심.

브랜드별 차이점:
- MAZI UNTITLED: 가방 브랜드, 성비 상대적 균등, 객단가 10~20만원대
- COSSET COSSET: 유아복, 여성(엄마) 중심, 시즌성 강함

## 설계 순서
1. 고객을 아래 4퍼널(MECE)로 나누고, 캠페인이 어느 퍼널에 속하는지 명시한다.
2. 세그먼트별 목표 행동(첫구매 / 재구매)을 정한다.
3. 쿠폰·메시지·타이밍·채널을 분리해 설계한다.
4. 실험군/대조군 또는 전후 비교 기준을 발송 전에 정한다.

## 4퍼널 정의 (2026-02 확정)

| 퍼널 (SEG) | 정의 | 핵심 관리 지표 |
|------------|------|---------------|
| 1. 신규 회원 (미구매자) | 가입 후 0회 구매 | 첫구매 수 |
| 2. 활성 (Loyalty) | 구매 1회+, 마지막 방문 100일 이내 | 재구매 수 |
| 3. 이탈 (Churned) | 구매 1회+, 마지막 방문 101~365일 | 재구매 수 |
| 4. 휴면 (Lapsed) | 구매이력 있는 회원 중 마지막 방문 366일 이상 | 재구매 수 |

- 이전 버전(5퍼널, 80일 기준)에서 4퍼널 체계로 변경됨. 기준은 "방문"이다 (구매일 기준 아님).
- 100일 경계는 재구매 주기 80~95일인 의류 브랜드 기준과 맞물린 값으로 보인다(추정). MAZI(가방)·COSSET(유아복)에 적용할 때는 자사 재구매 주기로 경계를 재검증한다.

## 캠페인 운영 체계

### 캠페인 기록 항목
데이터라이즈 기반 캠페인은 아래 정보를 포함해 기록한다:
- 주차 / 액션 내용 / 목표 조건 / 성별 / 쿠폰 사용여부 / 채널(카톡/SMS) / 발송일
- 측정 항목: 발송 수, 발송비율, 오픈수, 실 발송 수, 클릭 수, 반품 수, 구매전환 수, 구매액, 기여 금액

### 검증된 캠페인 유형 (2026-02 기준)
- 미구매/리텐션/윈백 활성화 (신규, 재구매 유도)
- 이탈/휴면 고객 대상 최근 구매 이력 기반 리타겟
- 장바구니 이탈 7일 이내 상품 리마인드
- 주문서 작성 중 이탈 고객 대상 상품 추천
- 쿠폰 사용 마감 알림

## 쿠폰 정책 원칙

### 공통
- 할인 남발은 브랜드 가치와 마진을 훼손한다. **목적 없는 쿠폰 제안 금지.** 쿠폰을 넣을 때는 대상 퍼널·목적·허들 근거를 함께 제시한다.
- 활성(Loyalty) 고객은 정가 구매 유지를 기본으로 한다. 쿠폰은 이탈·휴면 회수에 우선 배정한다.

### 참고 사례: 남성 의류 브랜드 정책 (2026-02 확정)
| 퍼널 | 쿠폰 허용 | 이유 |
|------|-----------|------|
| 신규 회원 | 조건부 (여성 타겟 한정) | 남성 회원 비중이 압도적 → 남성은 정가 습관화 |
| 활성 (Loyalty) | ❌ | 정가 구매 유지, 디브랜딩 방지 |
| 이탈 (Churned) | ⭕ 조건부 | 이탈 전 마지막 기회 |
| 휴면 (Lapsed) | ⭕ 강한 오퍼 | 회수 목적 |

리워드 쿠폰 허들: 10만원 → 20만원 상향 후 AOV 8% 증대 실증.

### MAZI UNTITLED (미정)
⚠️ CRM 설계 전. 성비 균등이므로 위 사례의 "여성 한정" 정책과 다른 전략 필요.

### COSSET COSSET (미정)
⚠️ CRM 설계 전. 여성(엄마) 중심이므로 성별 조건 자체가 불필요. 시즌성을 고려한 별도 설계 필요.

## CRM 논의 시 규칙
- 새로운 캠페인 제안 시 반드시 4퍼널 체계 안에서 위치를 명시
- "이 캠페인은 이탈(Churned) 세그먼트, 여성, 101~200일 미방문 타겟"처럼 구체적으로
- 쿠폰 포함 캠페인은 반드시 쿠폰 정책 원칙과 충돌하지 않는지 체크
- 효과 측정은 발송 수 → 클릭 수 → 구매전환 수 → 구매액 → 기여금액 순서로 리포트
- 테스트 설계 시 단일 변수 A/B 테스트 우선 (복합 변수 동시 테스트 지양)
- 측정 KPI: 첫구매 수, 재구매 수 두 가지에 집중
- 개인정보 활용·수신동의 범위·실제 고객 발송(카카오/SMS)은 승인 경계다. 설계·초안·발송 대상 수 미리보기까지 진행하고, 발송은 승인 후 실행한다.

## 팩트체크 (분석/제안 완료 후 필수)
답변 제출 전 아래 3항목을 내부 검증한다:
- 제안한 캠페인이 4퍼널 체계의 올바른 세그먼트에 위치하는가?
- 쿠폰 정책 원칙과 충돌하지 않는가?
- 인용한 지표(클릭률, CVR 등)의 정의가 데이터라이즈 기준과 일치하는가?
검증 미통과 항목이 있으면 답변에 "⚠️ 정책 충돌 가능" 표기.
